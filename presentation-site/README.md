# N’KEMBA isolated static presentation

This directory contains only the public-facing static institutional presentation (HTML, CSS and a small language switcher). It is independent of the private N’KEMBA application and reconstruction engine.

- No API calls, uploads, analytics, cookies, credentials or external runtime dependencies.
- No legal, factual-certification or independent-audit claims.
- The page is marked noindex in its HTML while being prepared.
- Intended Render static-site publish directory: `presentation-site`.

This is a presentation page, not an evidence-analysis service. Keep the private application repository private. Do not add secrets, private source code, internal documents or customer data here.
